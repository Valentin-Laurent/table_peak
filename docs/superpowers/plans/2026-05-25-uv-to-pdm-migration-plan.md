# uv → pdm Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace uv with pdm as `table_peak`'s package/lockfile manager so Claude can run sync + lint + test autonomously under `sandbox.enabled: true`.

**Architecture:** Three phases. **Phase 1 (this session)** prepares Claude-writeable artifacts only — the new proposed `~/.claude/settings.json` and the new `Makefile` recipes. **Phase 2 (manual handoff)** has the user install pdm and apply the new settings, then restart Claude. **Phase 3 (fresh session)** runs the actual pdm install, regenerates `pdm.lock`, deletes `uv.lock`, and verifies end-to-end via `make check`. **Phase 4** is a documented rollback if Phase 3 verification fails.

**Tech Stack:** pdm 2.15+ (PEP 621 + PEP 735 native), GNU make, ruff, mypy, pytest. Fallback: pip + pip-tools (out of plan; new spec if triggered).

**Reference spec:** [`docs/superpowers/specs/2026-05-25-uv-to-pdm-migration-design.md`](../specs/2026-05-25-uv-to-pdm-migration-design.md).

**Cross-session continuity:** Phases 1, 3, and 4 may run in different Claude sessions (the settings paste in Phase 2 requires a restart). Each task is self-contained; a fresh session reading this plan can pick up at the first unchecked task.

### Task 1: Rewrite `Makefile` to use pdm + `.venv/bin/<tool>`

**Files:**
- Modify: `Makefile`

**Rationale for recipe choices:** `sync` uses `pdm install` because that's pdm's job. Hot targets (`lint`, `format`, `format-check`, `typecheck`, `test`) bypass `pdm run` and call `.venv/bin/<tool>` directly. This isolates everyday commands from any pdm runtime quirks the Phase 3 verification might surface — if `pdm run X` proves flaky under the sandbox, only `make sync` is affected, not the daily loop.

  Expected: matches the recipes documented in the spec (uv-based).

- [x] **Step 1.2: Replace the Makefile contents**

  Write the file in full with this body:

  ```makefile
  # table_peak — dev workflow wrapper.
  # Single Bash matcher `Bash(make:*)` covers the whole dev surface under
  # Claude Code; pdm is the underlying package/lockfile manager.
  #
  # Daily targets call `.venv/bin/<tool>` directly so they don't depend
  # on `pdm run` at runtime. `make sync` is the only target that invokes
  # pdm; run it after pulling or after dep changes.
  #
  # Run `make help` for the target list.

  .PHONY: help sync lint format format-check typecheck test check clean

  help: ## Show this help and the available targets
  	@awk 'BEGIN {FS = ":.*?## "; printf "Targets:\n"} /^[a-zA-Z_-]+:.*?## / {printf "  %-15s %s\n", $$1, $$2}' $(MAKEFILE_LIST)

  sync: ## Install / sync dependencies from pdm.lock into .venv
  	pdm install

  lint: ## Run ruff lint over src/ and tests/
  	.venv/bin/ruff check

  format: ## Apply ruff formatting (mutates files)
  	.venv/bin/ruff format

  format-check: ## Check ruff formatting without mutating
  	.venv/bin/ruff format --check

  typecheck: ## Run mypy --strict (config in pyproject.toml)
  	.venv/bin/mypy

  test: ## Run pytest
  	.venv/bin/pytest

  check: lint format-check typecheck test ## Run the full local-CI suite

  clean: ## Remove tool caches (.mypy_cache, .ruff_cache, .pytest_cache)
  	@for d in .mypy_cache .ruff_cache .pytest_cache; do \
  		if [ -e "$$d" ]; then trash "$$d"; fi; \
  	done
  ```
